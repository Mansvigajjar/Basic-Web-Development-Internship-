Download your song

Paste a Spotify track link. The app will send it to the RapidAPI endpoint you configure and show the result.

Setup required: Open app.js and enter the RapidAPI host, endpoint URL, and key using the provider's documentation. This template does not guess a provider-specific response format. Never upload API keys to a public GitHub repository. Use only audio that the service is authorized to distribute.
